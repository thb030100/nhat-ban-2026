# Character assets

The letter widget uses nine user-supplied character images:

- `doraemon-snack.png`
- `doraemon-walk.png`
- `doraemon-broom.png`
- `doraemon-fly.png`
- `naruto.png`
- `sakura.png`
- `totoro-umbrella.png`
- `shizuka.png`
- `kuromi.png`

`doraemon-walk.png`, `kuromi.png`, `doraemon-fly.png`, `sakura.png`, `totoro-umbrella.png`, and `shizuka.png` were prepared as transparent cutouts from the supplied files. Totoro is mirrored in CSS so the extended arm points toward the letter. The character-to-letter category mapping is defined in `companion-data.js`.

These characters are third-party intellectual property. Confirm publication rights and replace the files with appropriately licensed artwork before a public or commercial release.
