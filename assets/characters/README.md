# Character assets

The letter widget uses five user-supplied character images:

- `doraemon-snack.png`
- `doraemon-walk.png`
- `doraemon-broom.png`
- `naruto.png`
- `kuromi.png`

`doraemon-walk.png` and `kuromi.png` were prepared as transparent cutouts from the supplied checkerboard-background files. The character-to-letter category mapping is defined in `companion-data.js`.

These characters are third-party intellectual property. Confirm publication rights and replace the files with appropriately licensed artwork before a public or commercial release.
