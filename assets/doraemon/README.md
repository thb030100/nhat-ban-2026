# Doraemon image assets

Place the six licensed transparent images here:

- `morning-a.webp`
- `morning-b.webp`
- `afternoon-a.webp`
- `afternoon-b.webp`
- `evening-a.webp`
- `evening-b.webp`

Use transparent images in which Doraemon faces left and appears to hold or present a letter with one hand. Keep the crop and baseline consistent, ideally at least 512 × 512 px. The website falls back to a small letter seal when an image is unavailable. Add license and attribution details to this file when the assets are supplied.

After all six files are present, change `assetsReady` to `true` in `companion-data.js`.
